# Mangyan Digital Heritage React Website

## Run the project

Open a terminal inside this folder:

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal.

## Interactive / reactive buttons included

- Navigation buttons with smooth scrolling
- Dark/light mode button
- Mobile menu button
- Search box for Mangyan groups
- Filter buttons
- Group profile modal
- Gallery lightbox
- Expand/collapse cultural topics
- Community-today interactive cards
- Back-to-top button

## Important research note

The website is a student project template. Replace or verify cultural claims and add the exact references and image credits your group actually used. Do not invent sources, interviews, quotations, statistics, or image permissions.
